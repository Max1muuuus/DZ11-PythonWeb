# EventHub — платформа організації та бронювання заходів

Навчальний вебзастосунок на Django з ролями користувача, організатора та модератора.

## Запуск локально

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Відкрийте `http://127.0.0.1:8000/`. Панель модератора доступна за адресою
`http://127.0.0.1:8000/admin/`. Створіть суперкористувача командою `createsuperuser`,
щоб керувати ролями, користувачами, заходами та бронюваннями.

## Ролі та можливості

- **Користувач** реєструється, редагує профіль, шукає заходи, бронює їх і переглядає історію.
- **Організатор** (роль `admin`) створює, редагує, публікує та видаляє власні заходи.
- **Модератор** керує всіма заходами та бронюваннями в панелі, а також керує користувачами й ролями.
- Нові реєстрації завжди створюють звичайного користувача. Ролі призначає модератор у `/admin/`.

Бронювання дозволене лише для опублікованих майбутніх заходів, не дозволяє дублікати,
бронювання власного заходу чи перевищення місткості. Скасовані та завершені заходи
не можна бронювати.

## Перевірки

```powershell
python manage.py test
python manage.py check
```

Перед розгортанням задайте `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0` та `DJANGO_ALLOWED_HOSTS`.
Для реального розгортання також потрібні відповідні HTTPS, база даних і поштові налаштування.
